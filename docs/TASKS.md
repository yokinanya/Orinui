## 本批补齐的本地规范项

- [x] Dashboard Icons 图标目录参考外链，仅导航，不抓取图标。
- [x] 手动仅清除图片来源 URL，事务清理共享引用来源并保留图片；界面说明立即生效。
- [x] 主页进入和分组内容切换轻量动效，减少动态效果下移除位移；异步切组确认数据归属。

上述代码补齐了既有视觉/数据规范。当前 JSON 备份只支持版本 1，没有已声明支持的旧 JSON 格式，故不把旧版兼容迁移作为凭空新增的任务；IndexedDB 迁移是另一套版本体系。

## 已确定的范围

- [x] 默认中性渐变；MVP 不随包提供第三方摄影图片。
- [x] 保留本地照片上传和用户主动图片直链下载。
- [x] MVP 不提供联网搜索建议；搜索只在用户提交时发出。
- [x] 同步分组、网站、设置、照片和图标。
- [x] 同步提供方选择 Drive appDataFolder（推荐）或 HTTPS WebDAV；不创建 Orinui 账号或自营后端。
- [x] 一个同步库使用一个提供方；云端快照与媒体强制端到端加密。
- [x] 同步采用每设备快照、字段级逻辑版本和墓碑；默认关闭，用户启用后异步同步，不定时轮询。

取舍依据见 [DECISIONS.md](./DECISIONS.md)。上述条目表示方向已定；当前仅同步基础层已完成，提供方和连接流程未接入。
