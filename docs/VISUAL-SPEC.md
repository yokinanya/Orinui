# Orinui 视觉规格（已确认）

> 范围：产品视觉与页面交互；不含代码实现、数据契约最终定稿或工程初始化。已按用户确认作为后续视觉稿与实施基准。

## 设计目标

- 方向：沉浸留白，结合精致的网站分组管理；自然壁纸提供氛围，搜索与快捷方式保证效率。
- 气质：安静、明亮但不过曝、轻盈克制；默认界面开箱即用，不像管理后台。
- 不照搬 Material 组件外形。借鉴 Material You 的动态语义色系统，并保留新标签页摄影与留白的品牌感。

## 页面构成

### 默认主页

- 背景支持三类：随包提供的少量授权自然摄影（首张为默认）、纯色、渐变；用户也可上传照片或粘贴图片直链下载到本地。页面渲染只读取本地图片，不在打开新标签页时联网取图。
- 页面主体纵向排列：大号轻字重时钟与较小日期 → 主搜索框 → 紧凑分组标签及快捷网站网格。
- 主体维持有限最大宽度并居中；网格宽屏最多 6 列，随窄窗口自适应减少列数与间距。内容超出窗口时页面自然纵向滚动。
- 搜索框宽而克制，使用轻度半透明/磨砂表面；获得焦点时边界与焦点指示增强。对比度需在最终壁纸集合上实测。
- 分组采用紧凑文本标签，当前项用细线或轻柔半透明背景表示；组多时横向滚动。分组操作（改名、删除、左右移动）从标签的右键菜单进入。
- 网站图标在上、名称在下，无固定卡片底；图标大小统一，长名称截断且提供可访问名称。空网格可直接显示明确的添加引导。
- 图标可选四类来源：文字/首字母、内置基础图形、本地上传、从图片直链下载到本地。不按网站地址自动抓取 favicon，也不在打开新标签页时加载远程图标。设置中提供 Dashboard Icons 等图标目录的参考外链，用户自行复制直链后粘贴。
- 右下角放一个低对比设置图标；悬停或键盘聚焦时显示轻薄圆形底。设置抽屉只负责外观与布局，网站和分组的编辑在主页完成，不放在抽屉里。

### 首次进入与内容状态

- 创建一个空的“常用”分组，不预置示例网站，不读取书签。
- 网格中央显示“添加第一个网站”主操作；设置入口始终可见。
- 设计稿另覆盖已配置网站、多分组、密集网站、长名称、编辑模式和分组空状态，但这些示例数据只用于视觉演示，不写入新用户数据。

### 主页的网站与分组管理

- **操作入口以右键菜单为主**：右键任意网站格子或分组标签即弹出该对象的操作菜单，不需要先进入任何模式，也不依赖 hover。
- 每个操作都有一条不依赖鼠标的路径：编辑模式下网站格子与分组标签显示可 Tab 聚焦的「⋯」按钮，`Shift+F10`／菜单键同样打开右键菜单。
- 分组标签行末尾的「编辑」按钮切换编辑模式。进入后网站格子与分组标签可拖动排序，网格末尾出现「＋ 添加网站」格子，标签行出现「＋」新建分组。
- 编辑模式下「⋯」与所属对象在视觉上是一个整体：分组标签把按钮收进同一个胶囊，网站格子把按钮放在格子内的右上角。不单独悬浮在对象之间。
- 键盘路径：空格拿起被聚焦的对象、方向键移动、空格放下、`Escape` 取消；`Enter` 仍保留给对象自身的动作（分组标签用它切换分组）。每个对象只占一个 Tab 停靠点。
- 拖动只做组内排序；跨分组移动用菜单里的「移动到分组」。
- 网站菜单：编辑、上移、下移、移动到分组、删除。删除后 5 秒内可撤销。
- 分组菜单：重命名、左移、右移、删除分组。默认分组的删除项禁用。
- 分组重命名用对话框而不是行内输入框：标签行空间紧凑，行内输入会把整行撑开。
- 删除分组用二次确认对话框，确认前显示组内网站数量；破坏性操作在菜单中单独分隔并着色区分。

### 设置及编辑面板

- 从右下角入口打开右侧抽屉；保留主页背景作上下文，面板采用足够不透明的表面层，确保内容易读。
- 面板只含外观、布局与关于（数据导入导出随后续阶段加入）；网站与分组不在这里管理。
- 抽屉具可见关闭操作、可访问标题、正确焦点移动/恢复与键盘关闭行为。窄视口具体尺寸在原型验证时再定。
- 面板内容是纵向滚动容器；内边距放在滚动容器自身，避免装饰性控件（如开关扩大的点击热区）在内容盒外造成横向滚动。
- 颜色选择用自建取色面板，不用系统取色弹窗：原生弹窗由浏览器绘制，无法跟随应用的圆角、间距与语义色，放在设置面板里就是一块异色区域。面板含饱和度/明度面板、色相条、十六进制输入与屏幕吸管；键盘可达任意颜色（方向键调色相与饱和度/明度，十六进制输入可直接键入）。
- 抽屉不画与页面之间的分界线：遮罩与阴影已足够区分层次，一条发丝线在深色主题下反而比抽屉本身更抢眼。

## 颜色与主题

### 动态色（Material You-inspired）

- 默认开启本地动态取色：仅在设备本地提取种子色并生成协调的浅/深色语义色角色；图片像素与种子色不上传。照片背景从图片提取，纯色背景直接使用该颜色，渐变背景取渐变中点色。
- 默认配色模式为“跟随当前背景”。用户手动选择种子色后锁定该色，后续换壁纸不会覆盖；可通过“恢复跟随背景”重新自动取色。
- 用户手动调整入口在外观设置内：色板就是取色面板的触发器，点开是「饱和度/明度面板 + 色相条 + 十六进制输入 + 屏幕吸管」的弹层，面板内取到的颜色即时预览，收起后落定。
- 动态色主要用于强调色、当前分组、选中/焦点状态；只给搜索框和设置抽屉等半透明表面轻微色调。大面积背景仍使用用户照片，正文与次级信息保持暖中性层次，错误色保持固定语义。
- 取色失败、图片无效或当前为纯色背景时，回退到中性暖白/石墨灰的静态种子色；不得产生空白主题或阻塞新标签页显示。
- 系统约束：Chrome 扩展不能直接读取操作系统壁纸或系统强调色；这里的动态色来源是扩展自己的当前壁纸，不宣称读取 Android/ChromeOS 系统主题。

### 明暗模式与可读性

- 默认跟随系统浅/深色，提供浅色、深色手动覆盖。
- 明暗模式决定文字/控件层级和背景遮罩倾向；遮罩强度设置仅对照片背景显示，纯色与渐变背景不显示该控件。
- 文字、图标和交互边界使用语义令牌配对。避免依赖照片本身保证对比；正文对比度目标不低于 WCAG AA，焦点和必要控件边界达到适用的非文本对比要求。最终值需用实际壁纸组合验证。
- 视觉基色为中性暖白、石墨灰；动态色仅做轻强调，不把全页染成壁纸取样色。

## 字体、形状与层次

- 使用系统无衬线字体栈及适当 CJK 系统回退，不远程加载字体、不额外打包字体；兼顾 Windows/macOS/Linux 常见平台。
- 时钟大号、轻字重、清晰易读；日期较小。搜索输入与快捷名称采用舒适正文尺寸，次级标签仍需可读。
- 圆角、间距、字体等级、颜色和焦点样式均用语义设计令牌管理；不在本稿锁定未经原型验证的像素数值。
- 主界面尽量平面、无卡片墙；抽屉、弹出建议和输入表面通过低强度色调/边界与背景区分，阴影只在壁纸复杂、确有分层需要时使用。
- shadcn/ui 用于抽屉中的表单、选择器、按钮等，不要求首页变成标准 shadcn 仪表盘。组件使用语义色，不逐处硬编码颜色。

## 固定插槽与布局设置

- 主页只配置三个命名显示区域：`clock`、`search`、`shortcuts`；分组标签和网站网格属于同一个 shortcuts 区域。
- 默认纵向顺序为时钟 → 搜索 → 快捷方式。设置面板提供各区域显示开关与上移/下移按钮；不提供拖拽、任意坐标、尺寸调整或嵌套布局。
- 右下角设置入口不属于可隐藏/排序区域，保证用户总能恢复页面配置。
- 若所有内容区域均隐藏，仍保留设置入口与可发现的恢复提示，避免用户失去控制入口。

## 搜索建议与焦点

- 默认不自动聚焦，避免打开新标签页即弹出输入法或打断键盘操作；点击输入框或按 `/` 可聚焦。快捷键不应覆盖正在编辑文本的其他表单字段。
- 搜索建议默认关闭联网功能。设置开启前清楚说明查询会发送给单一外部服务，并明确取得用户授权；撤销权限或关闭后不再请求。
- 启用后，建议在输入框正下方列表浮层显示；支持上下选择、Enter 提交与 Escape 收起，不遮挡主要快捷网站。请求失败不阻断手动搜索，不保存查询历史。
- 搜索建议服务尚未选定；实现前必须核验服务条款、接口稳定性、MV3 权限/CSP 与请求可行性，不能把视觉确认误当成服务接入授权。
- 网站快捷方式点击后在当前标签页打开。

## 动效、响应式与无障碍

- 页面进入/分组切换仅用轻量淡入或微位移，目标时长约 150–220ms；动画不得延迟搜索可用或链接点击。
- 尊重 `prefers-reduced-motion`，启用减少动态效果时关闭非必要位移/过渡。
- 同一纵向构图适配窄窗口，列数与间距自适应减少；分组标签可横向滚动；主体不溢出视口宽度。
- 所有操作可键盘访问，焦点轮廓清晰，图标按钮有名称，颜色不是唯一状态标识；排序同时提供拖动与菜单里的上移/下移（分组为左移/右移），键盘用户不必拖动。
- 右下设置按钮不能被内容滚动遮住；检查键盘焦点态、复杂壁纸对比、缩放与窄宽度布局。

## 目前已确认的首选默认行为

| 事项 | 已确认选择 |
|---|---|
| 视觉方向 | 沉浸留白 + 精致网站分组管理 |
| 背景 | 照片（随包自然摄影为首张默认，也支持本地上传与图片直链下载）、纯色、渐变；全屏铺满，照片可调遮罩 |
| 动态色 | 默认开启并跟随当前背景本机提取；手动选色后锁定，用户可恢复自动跟随；轻度用于强调与半透明表面 |
| 明暗主题 | 跟随系统，允许手动固定浅/深色 |
| 字体 | 清晰现代无衬线，系统字体栈，不随包打包字体 |
| 布局 | 时钟、搜索、分组/网格自上而下；最多 6 列，页面自然滚动 |
| 快捷方式 | 图标上、名称下、透明无卡片底；不预置示例站点 |
| 图标来源 | 文字/首字母、内置基础图形、本地上传、图片直链下载到本地；不自动抓取 favicon |
| 分组标签颜色 | 语义色角色（默认组用 primary），不存任意 RGB |
| 初始空状态 | 空的“常用”组，显示“添加第一个网站” |
| 分组导航 | 紧凑文本标签，当前项轻强调，窄宽度横向滚动；右键标签进入改名/删除/移动 |
| 设置入口 | 右下角低对比图标，焦点/悬停出现轻薄底 |
| 设置呈现 | 右侧抽屉；只含外观、布局与关于，网站与分组在主页编辑 |
| 取色控件 | 自建弹层（饱和度/明度、色相、十六进制、吸管），不使用系统取色弹窗；写入始终是 `#rrggbb` |
| 主页编辑 | 右键菜单随时可用；标签行末尾「编辑」按钮切换拖动排序与添加入口 |
| 时钟 | 跟随系统区域设置 |
| 搜索引擎 | Google；可在设置中更改 |
| 搜索焦点 | 初始不聚焦；点击或 `/` 聚焦 |
| 网站打开方式 | 当前标签页 |
| 动效 | 轻量淡入/微位移约 150–220ms；遵从减少动态效果 |
| 布局自定义 | 三个固定区域显示开关与上/下移；无拖拽/任意定位/尺寸控制 |

- 壁纸数量、具体授权资源、最终设计令牌数值与断点由后续视觉原型和性能验证确定；不在此阶段凭空锁定。
