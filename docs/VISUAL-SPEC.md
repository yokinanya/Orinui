# 视觉与交互规范

本页为现行规则，不代表全部验收通过。实现见 [TASKS](./TASKS.md)，证据见 [VERIFICATION](./VERIFICATION.md)；必要历史见 [VERIFICATION](./VERIFICATION.md)。

## 主页

- 沉浸留白、Niagara 风格：顶部时钟/日期、下方搜索、左侧固定双列内容，右侧留给壁纸。网站/一层文件夹为 48px 图标加名称的横向单格，不提供四模板、角落、区域排序、列数或隐藏名称开关。
- 便签/待办可多实例，占一列 2/3/4 行，每行 80px；按行、列、稳定 ID 排列，可留空位，碰撞只下推目标列实际碰撞链。删除保留空洞，恢复布局保留组件文字并紧凑排列。
- 页面宽度、区域间距、区域显隐、时钟格式/大小及网站打开方式可设。所有区域隐藏时仍有设置和恢复入口；不预置示例网站/文件夹、不读取书签。
- 文件夹最多一层，点击打开同主题弹层；删除前确认网站返回主页。网站菜单支持编辑、移入/移出与删除，删除后 5 秒内通过操作中心撤销。

## 添加、整理与保存

- 右下角添加统一网站、文件夹、便签、待办；另有整理/完成、设置及条件显示的播放和任务入口。提示向左，不遮挡邻近操作。
- 整理时显示格位和末尾空行。整卡空白可拖，按释放指针选格，移动保持卡片当前尺寸；输入、勾选与菜单保留自身交互。内容底部留白作为拖拽起点，不设左下角抓手或位置按钮。
- 便签/待办的高度只由右下角手柄拖动调节：按住上下移动按半行吸附到 2/3/4 行，松手提交，纯点击不改高度。手柄共用整卡拖动层，不启动卡片移动。
- 聚焦卡片：Space 拾起、方向键选格、Space 放下、Esc 取消；输入内不接管按键。格位仅视觉提示，手柄不进入 Tab 序列。
- 整理、删除、改高和移动不自动滚到底，禁用格位重绘滚动锚定。新增真实保存成功后只将新卡片按最近边界即时滚入视口并聚焦，不提前滚动。
- 便签/待办停止输入 600ms 自动保存，失焦立即提交；串行写入保护最新草稿。未保存/保存中及错误重试可见，成功后状态清空；待办成功后才清空输入。未保存内容触发离开提醒，不承诺强制结束时保存。
- 网站编辑显示真实草稿预览；取消不写入。“保存并继续添加”仅新增可用，成功后保留目标文件夹、清空本条内容并聚焦地址，失败保留草稿。名称留空显示域名。

## 搜索与时钟

- 搜索提示默认空字符串，允许自定义，不覆盖已有提示。默认不聚焦；可设首次加载聚焦一次，设置刷新不抢焦点；点击或 / 聚焦，不覆盖其他输入。
- 引擎图标为 32px 透明触发区，菜单显示图标/名称，不抓 favicon。结果按工具、网页搜索、网站、文件夹分区；答案和动作明确，底部键盘提示稳定。
- 圆角 8/16/24px，默认 16px；背景不透明度默认自动，可选 0–100%，不改变文字透明度。输入无常态外框、底线或双描边。
- 仅用户提交才联网，不保存查询、不读剪贴板、不提供联网建议。引擎、拼音、gh 和单行工具详见 [SEARCH-DESIGN](./SEARCH-DESIGN.md)。
- 时钟默认系统区域、标准大小、有日期/完整星期、无秒；日期格式和显隐可设。搜索/网站默认当前页打开，可独立改新标签页；原生链接保留中键和修饰键。

## 外观与壁纸

- 外观直接选默认、纯色、渐变、壁纸；默认中性渐变，无随包第三方摄影。纯色/渐变即时生效；素材库选中仅预览，明确应用后才更换。
- 添加壁纸仅本地照片/MP4/WebM/GIF/动画 WebP 与主动静态图片下载；进入添加页不修改背景、不预填旧素材。上传成功加入并应用，显示新素材封面/遮罩，旧素材保留。
- 桌面列表与详情约 1.8:1，列表独立滚动。详情有名称、已应用标记、更多菜单和关闭；重命名/删除归入更多，未应用才显示应用按钮。详情元信息包含类型、尺寸、大小、视频时长与来源。
- 详情内容填满头部/预览以外剩余高度，普通内容不出现多余滚动条，仅真正长内容溢出时独立滚动；不靠隐藏滚动条裁切控件。返回恢复入口焦点，不叠加设置对话框。
- 当前素材的来源/清除及遮罩并入详情，遮罩 0–100%、步长 1%。调整遮罩保持视频节点与播放位置，遮罩独立绘制，避免闪烁。
- 预览播放按钮仅当前已应用动态素材显示，有稳定可读底色；主页按钮控制当前背景。视频静音循环，暂停保留画面并续播；GIF/WebP 暂停用封面。后台/失焦按播放意图暂停恢复，减少动态效果默认静态，允许主动播放。
- 媒体首屏与取色使用本地封面，不逐帧取色；读取/解码/播放失败明确提示。

## 设置与数据

- 居中面板最大 76rem，受视口减 2rem 限制；左侧外观/布局/搜索/数据/关于，右侧内容。统一高不透明暖中性表面、轻边框、适量模糊，标题仅“设置”。
- 内容容器达到 52rem 双列独立堆叠，否则单列；不为跨列对齐留白，不用横向滚动承载表单。分区标题 16px/medium、次级 14px/medium，圆角不大于面板。
- 外观左主题/背景右配色；布局左页面/恢复右时钟/网站；搜索左搜索框/结果右行为/引擎；数据左备份/本地右同步。网站/文件夹管理留在主页。
- 配色开关“启用动态配色”，来源跟随背景/手动选色，手动称主题色。取色面板包含饱和度/明度、色相、HEX 和屏幕吸管，支持键盘，不用异风格系统取色窗。
- 本地 ZIP 默认不加密，恢复先展示网站/文件夹/便签/待办/壁纸/媒体数量后确认完整替换；重置确认列出小组件及其他删除内容。
- WebDAV/S3 配置可展开但保持挂载，状态/错误可见。服务模板切换不联网、不申请权限；凭据、恢复密钥、合并和远端删除风险不得为简洁而省略。同步详见对应设计文档。
- 设置状态文字 300ms 尾沿防抖，错误立即显示；不延迟真实持久化。撤销面板自动展开不夺焦点，设置关闭恢复焦点。

## 视觉与可访问性

- 共用语义色、表面、圆角、间距、焦点与动效；系统无衬线字体，不联网加载字体。文字简短，保留风险和可操作错误，不展示内部工程术语。
- 默认跟随系统明暗；本机动态取色轻用于强调，不全页染色。照片/动态背景文字用白字、深描边与柔光，控件根据封面/遮罩适配，独立于动态配色开关。
- 时钟/日期与空状态无底色；文字、图标和边界按实际背景验证 WCAG AA，不以平均亮度或少量抽样宣称全面达标。
- 主页图标外框 48px、编辑预览 64px，图案占比 50–100%、默认 75%、步长 1%；预览透明底细边框。安全静态 SVG 可保留矢量/选单色，背景 SVG 栅格化。
- 动效约 150–220ms，仅轻淡入/微位移，不延迟交互，尊重减少动态效果。图标按钮有名称、焦点清晰，长名称可省略但保留全名；破坏性操作确认或撤销。
- 当前优先桌面/横屏；保留基础窄屏回归，竖屏专项延期，不自动改为单列。真实读屏、触摸、复杂背景、扩展与用户验收分别记录。
