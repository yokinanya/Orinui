# Orinui 视觉规格（已确认）

> 本文件是已确认的视觉与交互规范，包含实施目标；不代表全部已完成。实现缺口见 [TASKS.md](./TASKS.md)，复杂背景对比、响应式和键盘焦点验收见 [VERIFICATION.md](./VERIFICATION.md)。

## 设计目标

- 方向：沉浸留白，结合精致的网站分组管理；自然壁纸提供氛围，搜索与快捷方式保证效率。
- 气质：安静、明亮但不过曝、轻盈克制；默认界面开箱即用，不像管理后台。
- 不照搬 Material 组件外形。借鉴 Material You 的动态语义色系统，并保留新标签页摄影与留白的品牌感。

## 页面构成

WebDAV 已连接面板提供“删除远端同步库”危险操作；未连接时，留空恢复密钥检查出已有库，在错误提示后显示“忘记恢复密钥？”。两个入口均使用二次确认，说明云端配置、所有设备快照和图片将永久删除、本机数据保留，并提示停止其他设备同步。处理中禁止重复确认与关闭，失败保留确认框并显示真实错误；忘记密钥的删除完成后返回检查连接，不自动新建库。

### 默认主页

- 背景支持默认中性渐变、纯色、渐变和照片；用户可上传照片或粘贴图片直链下载到本地。首版不内置第三方摄影素材。页面渲染只读取本地图片，不在打开新标签页时联网取图。
- 页面主体纵向排列：大号轻字重时钟与较小日期 → 主搜索框 → 紧凑分组标签及快捷网站网格。日期与星期可独立隐藏；两者都隐藏时不保留空白行。
- 页面最大宽度可选 640 / 768 / 1024px，默认 768px；区域间距可选 24 / 40 / 56px，默认 40px。网站网格最多 4 / 6 / 8 列，默认 6 列；列数随可用宽度减少，网站少于一整行时居中。内容超出窗口时页面自然纵向滚动。
- 时钟大小为小/标准/大，窄屏和宽屏字号分别为 48/60、60/72、72/96px；空间不足时进一步自适应。显示秒数时按秒更新，否则在分钟边界刷新。
- 日期可选本地化月日、本地化年月日或本地日历 `YYYY-MM-DD`。星期可选本地完整、本地简写或固定英文 `Mon`–`Sun`。
- 搜索框最大宽度可选 448 / 576 / 704px，默认 576px；默认提交后在当前页打开。网站名称默认显示，可隐藏；隐藏时仍保留链接的可访问名称和悬停提示。网站与搜索结果可独立选择当前页或新标签页。
- 搜索框采用半透明表面，不画常态外框；输入或聚焦时不显示底部白线、双描边或外扩阴影。对比度需在实际壁纸组合上实测。
- 分组采用紧凑文本导航，当前项以字重和短下划线区分；默认背景无外围框或三点按钮。自定义纯色、渐变背景上的分组标签及日期使用局部半透明底层，保证强反差位置的文字可读；照片上的文字保留必要字形可读性处理。组多时保留横向滚动并隐藏原生滚动条；改名、删除、左右移动从标签右键菜单进入。
- 网站图标在上、名称在下，无固定卡片底；主页图标外框固定 48px，图案可在框内按 50–100% 占比调整（默认 75%，步长 1%），外框尺寸不变。编辑预览外框固定 64px，透明底并带细边框；占比只改变边框内的图案。长名称截断且提供可访问名称。空网格显示明确的添加引导，容器背景透明，保留边界、文字和按钮。
- 图标可选四类来源：文字/首字母、内置基础图形、本地上传、从图片直链下载到本地。不按网站地址自动抓取 favicon，也不在打开新标签页时加载远程图标。符合安全白名单的静态 SVG 图标保留为本地 SVG；照片背景中的 SVG 仍栅格化为 PNG。网站图标编辑的 URL 栏旁提供 Dashboard Icons 链接，用户自行复制图标链接。
- 右下角放一组低对比操作：编辑按钮在上，设置按钮在下，悬停或键盘聚焦时显示轻薄圆形底。设置面板负责外观、布局、搜索和本地数据；网站和分组的编辑在主页完成，不放在设置面板里。

### 首次进入与内容状态

- 创建一个空的“常用”分组，不预置示例网站，不读取书签。
- 网格中央显示“添加第一个网站”主操作；设置入口始终可见。
- 设计稿另覆盖已配置网站、多分组、密集网站、长名称、编辑模式和分组空状态，但这些示例数据只用于视觉演示，不写入新用户数据。

### 主页的网站与分组管理

- **操作入口以右键菜单为主**：右键任意网站格子或分组标签即弹出该对象的操作菜单，不需要先进入任何模式，也不依赖 hover。
- 每个操作都有一条不依赖鼠标的路径：`Shift+F10`／菜单键在网站或分组上打开右键菜单；编辑模式下网站格子另保留可 Tab 聚焦的「⋯」按钮，分组不增加额外操作按钮。
- 主页右下角的编辑按钮切换编辑模式。进入后网站格子与分组标签可拖动排序，网格末尾出现「＋ 添加网站」格子，标签行出现「＋」新建分组。
- 编辑模式下网站「⋯」在格子内的右上角，不单独悬浮在对象之间。分组标签自身是拖动和切换的入口，编辑态不另加外框。
- 键盘路径：空格拿起被聚焦的对象、方向键移动、空格放下、`Escape` 取消；`Enter` 仍保留给对象自身的动作（分组标签用它切换分组）。每个对象只占一个 Tab 停靠点。
- 拖动只做组内排序；跨分组移动用菜单里的「移动到分组」。
- 网站菜单：编辑、上移、下移、移动到分组、删除。删除后 5 秒内可撤销。
- 分组菜单：重命名、左移、右移、删除分组。默认分组的删除项禁用。
- 分组重命名用对话框而不是行内输入框：标签行空间紧凑，行内输入会把整行撑开。
- 删除分组用二次确认对话框，确认前显示组内网站数量；破坏性操作在菜单中单独分隔并着色区分。

### 设置及编辑面板

- 从右下角的设置入口打开居中设置面板；分区标签在左侧纵向排列，右侧显示内容。保留主页背景作上下文，面板使用统一的高不透明度暖中性表面与轻微背景模糊；左侧仅用低强度底色区分，当前标签为柔和圆角底。内容可滚动但隐藏滚动条，标题只显示“设置”。
- 面板含外观、布局、搜索、数据与关于；布局页分页面、时钟、网站三组，以留白和淡分隔明确层级。各页的分段选项使用相同的低对比容器和柔和选中态，区域列表沿用同一表面层次。宽容器中设置项采用左侧标签、右侧定宽选项的对齐行；窄容器中纵向排列，选项文字不折行。主页区域用紧凑列表承载拖拽手柄、上移、下移和显隐操作，宽容器中显示序号；“恢复主页内容”紧随列表，“恢复默认布局”位于全页末尾。网站与分组不在这里管理。
- 数据面板以“本地备份”标题和导出/导入按钮组成单行；省略重复说明，导入前的汇总预览和替换确认仍保留，错误明确显示。
- WebDAV 连接表单使用带明确选中状态的服务模板选择器，提供坚果云、Koofr、Nextcloud 与自定义，默认坚果云。坚果云预填官方地址但地址仍可编辑；Nextcloud 提供个人 WebDAV 地址示例。保留官方设置方法链接，不展示重复说明。切换模板清空旧连接草稿；检查中或已有合并计划时禁用选择，不因选择模板联网或申请权限。
- WebDAV 首次合并预览保持紧凑：用一张无卡片墙的数量表对照本机/云端分组、网站和图片数量，附一句简短合并影响说明。新建库的恢复密钥不用单独卡片，标题和一次性提示紧邻只读输入与复制图标；复制不自动确认已保存。保存确认使用主题复选框，底部主操作明确、取消弱化；窄容器按钮纵向排列。
- 背景类型提供带边框与明确选中状态的默认、纯色、渐变、图片四项；主题模式、背景类型等单选项选中时使用主题主色及配对文字色，未选项保留中性边界。切换背景类型时只展示对应配置。图片配置中，来源清除为 URL 标签旁的图标按钮，保存动作使用保存图标；URL 有未保存更改时显示简短状态。
- 照片遮罩强度使用 0–100%、步长 1% 的滑动条，当前百分比可见并支持键盘调整。
- 网站编辑的图标区显示透明底、带 1px 细边框的固定 64px 实时预览，占比滑块按预览框内可绘制区域调整图案，和主页 48px 外框使用同一占比，不额外缩小预览内容；取消编辑不写入。首字和内置图标入口采用图形按钮，内置图标在弹出网格内选择，不逐个显示名称，保留可访问名称和悬停提示。上传图片按钮与首字/内置图标按钮位于同一行。上传图片后取消内置选项的选中态。
- 图片 URL 区使用“自定义图片URL”标签，右侧提供图标按钮主动下载；来源清除用图标放在标签行，不显示常规保存/清除说明，仅在地址有未保存更改时显示简短状态。保留必要的跨来源目标确认和可读错误提示，不增加 cookie/provider 确认弹窗。
- 静态 SVG 图标在严格白名单验证后可保留原色渲染；用户可选择单色并设定颜色。单色通过本地 CSS mask 应用，不改 SVG 源内容；清除颜色后恢复 SVG 原色显示。该选项只适用于 SVG 图标，位图和背景不提供此控件。
- 横屏且宽度足够时，网站编辑弹窗加宽为双列；窄屏保持单列，内容滚动，保存/取消始终可见。
- 界面只保留简短标签、必要操作后果、格式限制与错误，不展示设计思路或重复操作说明。
- 面板具可见关闭操作、可访问标题、正确焦点移动/恢复与键盘关闭行为；窄屏按视口缩放，内容在面板内纵向滚动。
- 面板内容是纵向滚动容器；内边距放在滚动容器自身，避免装饰性控件（如开关扩大的点击热区）在内容盒外造成横向滚动。
- 颜色选择用自建取色面板，不用系统取色弹窗：原生弹窗由浏览器绘制，无法跟随应用的圆角、间距与语义色，放在设置面板里就是一块异色区域。面板含饱和度/明度面板、色相条、十六进制输入与屏幕吸管；键盘可达任意颜色（方向键调色相与饱和度/明度，十六进制输入可直接键入）。
- 设置面板用遮罩与阴影区分页面层次，不额外画抢眼的分界线。

## 颜色与主题

### 动态色（Material You-inspired）

- 默认开启本地动态取色：仅在设备本地提取种子色并生成协调的浅/深色语义色角色；取色计算不依赖外部服务。当前实现不外发图片；未来用户启用同步后，媒体与设置按独立的加密同步规则传输。照片背景从图片提取，纯色背景直接使用该颜色，渐变背景取渐变中点色。
- 默认配色模式为“跟随当前背景”。用户手动选择种子色后锁定该色，后续换壁纸不会覆盖；可通过“恢复跟随背景”重新自动取色。
- 用户手动调整入口在外观设置内：色板就是取色面板的触发器，点开是「饱和度/明度面板 + 色相条 + 十六进制输入 + 屏幕吸管」的弹层，面板内取到的颜色即时预览，收起后落定。
- 动态色主要用于强调色、当前分组、选中/焦点状态；只给搜索框和设置面板等半透明表面轻微色调。大面积背景仍使用用户照片，正文与次级信息保持暖中性层次，错误色保持固定语义。
- 纯色直接使用该颜色，渐变使用中点色；默认背景或没有可用种子色时不覆盖静态设计令牌。照片读取/取色失败必须明确显示错误，不伪造种子色或成功状态；页面仍保持可操作。
- 系统约束：Chrome 扩展不能直接读取操作系统壁纸或系统强调色；这里的动态色来源是扩展自己的当前壁纸，不宣称读取 Android/ChromeOS 系统主题。

### 明暗模式与可读性

- 默认跟随系统浅/深色，提供浅色、深色手动覆盖。
- 明暗模式决定文字/控件层级和背景遮罩倾向；遮罩强度设置仅对照片背景显示，纯色与渐变背景不显示该控件。
- 文字、图标和交互边界使用语义令牌配对。避免依赖照片本身保证对比；正文对比度目标不低于 WCAG AA，焦点和必要控件边界达到适用的非文本对比要求。最终值需用实际壁纸组合验证。
- 纯色与渐变背景按背景明暗切换局部控件表面与正文，控件表面半透明并带轻微主题色调，避免出现突兀的纯白/纯黑块；边界和当前分组强调色兼顾背景对比，搜索框常态边界清晰、聚焦时显示强调色轮廓。
- 时钟和日期在所有背景上均不带底色；空状态容器也保持透明，文字使用主题配对前景色。照片上的时钟、日期与网站名称采用白字、柔和阴影和字形描边；搜索与小控件按背景类型采用轻透磨砂和柔和边界，网站整格保持透明。纯色和渐变中的搜索等控件继续使用主题配对的局部阅读表面。以上处理独立于动态配色开关，分组角色用细线保留，焦点轮廓可见；用户选择的背景及照片遮罩保持原值，默认中性主页不增加阅读底层。照片文字的阴影/描边对比须按实际字形周边像素复验，不把隐藏字形后的壁纸中心对比当作新样式的验收。
- 视觉基色为中性暖白、石墨灰；动态色仅做轻强调，不把全页染成壁纸取样色。

## 字体、形状与层次

- 使用系统无衬线字体栈及适当 CJK 系统回退，不远程加载字体、不额外打包字体；兼顾 Windows/macOS/Linux 常见平台。
- 时钟大号、轻字重、清晰易读；日期较小。搜索输入与快捷名称采用舒适正文尺寸，次级标签仍需可读。
- 圆角、间距、字体等级、颜色和焦点样式均用语义设计令牌管理；不在本稿锁定未经原型验证的像素数值。
- 主界面尽量平面、无卡片墙；设置面板、菜单和输入表面通过低强度色调/边界与背景区分，阴影只在壁纸复杂、确有分层需要时使用。
- shadcn/ui 用于设置面板中的表单、选择器、按钮等，不要求首页变成标准 shadcn 仪表盘。组件使用语义色，不逐处硬编码颜色。

## 固定插槽与布局设置

- 主页只配置三个命名显示区域：`clock`、`search`、`shortcuts`；分组标签和网站网格属于同一个 shortcuts 区域。
- 默认纵向顺序为时钟 → 搜索 → 快捷方式。设置面板提供各区域拖拽排序、显示开关与上移/下移按钮；不提供任意坐标、尺寸调整或嵌套布局。
- 右下角设置入口不属于可隐藏/排序区域，保证用户总能恢复页面配置。
- 若所有内容区域均隐藏，仍保留设置入口与可发现的恢复提示，避免用户失去控制入口。
- 当三个区域都隐藏时，主页提供“恢复主页内容”按钮，单击恢复默认插槽与顺序；“恢复默认布局”还重置页面宽度、区域间距、网格列数与网站名称显示，保留时钟、搜索和打开方式。
- 布局设置页提供时钟格式/大小、秒数与日期/星期显隐、日期及星期格式、页面宽度、区域间距、列数、网站名称和网站打开方式。

## 搜索建议与焦点

- 默认不自动聚焦；可选择仅在主页首次加载完成时聚焦一次，修改设置或重新显示区域时不抢夺焦点。点击输入框或按 `/` 可聚焦，快捷键不覆盖正在编辑文本的其他表单字段。
- MVP 不提供联网搜索建议，输入内容不会在提交搜索前发送到建议服务。
- 当前采用“搜索只在用户提交后发送”的产品决策，服务选择、费用、密钥管理、条款与权限暂不进入 MVP。
- 搜索和网站链接的打开方式分别设置；网站使用原生链接，保留修饰键、中键及键盘操作。编辑模式优先进入编辑和排序行为。

## 动效、响应式与无障碍

- 页面进入/分组切换仅用轻量淡入或微位移，目标时长约 150–220ms；动画不得延迟搜索可用或链接点击。
- 尊重 `prefers-reduced-motion`，启用减少动态效果时关闭非必要位移/过渡。
- 同一纵向构图适配窄窗口，列数与间距自适应减少；分组标签可横向滚动；主体不溢出视口宽度。
- 所有操作可键盘访问，焦点轮廓清晰，图标按钮有名称，颜色不是唯一状态标识；排序同时提供拖动与菜单里的上移/下移（分组为左移/右移），键盘用户不必拖动。
- 右下设置按钮不能被内容滚动遮住；检查键盘焦点态、复杂壁纸对比、缩放与窄宽度布局。
