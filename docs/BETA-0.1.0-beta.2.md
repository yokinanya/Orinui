# Orinui 0.1.0-beta.2 候选说明（尚未发布）

本文是 `v0.1.0-beta.2` 的本地候选说明，不代表 GitHub Release 已创建。候选包、签名标签和源码推送都必须等待用户对具体候选版本的单独明确确认。

本文记录 2026-10-16 准备的旧本地候选（ZIP v2 / sync schema 4）。截至 2026-10-20，当前未发布源码格式为 Dexie 13 / ZIP v10 / sync schema 12，显式升级 Dexie 12/11、ZIP v9/v8 与同步 schema 11/10，见 [搜索设计](./SEARCH-DESIGN.md)。旧分组格式仍拒绝，不自动清理本地与远端。本文中的旧摘要和候选内容不代表当前源码构建，也未获发布授权。

## 本候选内容

- 壁纸素材库保留本机照片、GIF、动态 WebP、MP4 和 WebM；选择素材立即切换背景，删除当前项时经确认后切回默认渐变。
- 动态视频静音循环；页面不可见或窗口失焦时暂停，恢复后仅继续用户此前有播放意图的素材。减少动态效果默认显示封面。
- 搜索可在本地匹配所有分组的网站和分组，并提供安全计算、固定单位转换、带时区的时间转换及 `owner/repo#123` GitHub Issue/PR 导航。普通文本仍发送给当前搜索引擎。
- 本地完整备份使用 ZIP formatVersion 2，包含全部背景原件；导入先校验并显示预览，确认后事务替换本机数据。
- WebDAV 与 S3 提供方复用端到端加密同步；同步快照 schema 4 包含全部壁纸原件、未激活素材和删除墓碑。R2 以 Cloudflare S3 API 为目标服务。
- 长任务在操作入口显示阶段、文件及可取得的字节进度；同步设置可分别查看本机素材量、本轮传输估算和远端对象占用。

## 安装与更新

正式候选发布后，从同一 GitHub Release 下载扩展 ZIP 与配套 SHA-256 文本。先校验 ZIP 摘要，再解压到稳定目录；在 Chrome 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”并选中解压目录。后续更新覆盖同一目录的扩展文件，再在扩展管理页点击“重新加载”。

安装和更新使用同一个 Chrome 配置文件，以保留该配置文件的本地 IndexedDB、媒体和提供方凭据。不要为了升级而先删除扩展或清除扩展数据。

## 数据与兼容范围

- ZIP 是便携备份，不默认加密；请妥善保管。ZIP 不含 WebDAV/S3 登录凭据、恢复密钥、播放位置或运行状态。
- Beta 2 仅接受 ZIP formatVersion 2；开发期 JSON 和 Beta 1 ZIP v1 不兼容。不要依赖旧备份作为 Beta 2 的恢复路径。
- 同步仅接受 schema 4；Beta 1 schema 3 不兼容。遇到旧远端格式时会拒绝并保留本机及远端数据，不会自动清库或创建替代库。
- 扩展可保留当前 Chrome 配置文件中的本地数据，但先前已被旧版本清理的壁纸素材无法恢复。
- 更换 WebDAV/S3 位置不会自动搬迁或删除旧远端库；远端删除始终是单独确认的操作。

## 隐私、权限与已知限制

Orinui 无账号、广告或追踪。首页使用本地数据和资源；搜索只在用户提交时请求当前搜索引擎。联网图片下载及同步只在用户主动操作后请求对应来源权限。云端快照、图标及媒体原件均逐文件端到端加密；本地 ZIP 默认不加密。

上传使用单对象请求，不提供分块上传或断点续传。同步不自动重试，也不自动清理远端孤立对象。兼容性声明只覆盖在具体服务上的实际验收范围。窗口失焦、真实 Cloudflare R2、读屏器和触摸设备的验收结果以 [验证记录](./VERIFICATION.md) 为准。
