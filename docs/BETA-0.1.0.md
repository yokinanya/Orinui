## 本机性能观测

普通 Chrome 155 网页预览，素材为 35,709,002 字节、1920×1080、12 秒 MP4。以实际磁盘文件上传和恢复，避免测试协议传递大 Buffer 干扰数据。

| 操作 | 观测耗时 |
|---|---:|
| 初始空主页就绪 | 411 ms |
| 视频导入并生成封面 | 1.73 s |
| 刷新后恢复播放 | 209 ms |
| ZIP 导出 | 1.60 s |
| ZIP 验证与恢复 | 1.81 s |

ZIP 为 35,710,451 字节。操作期间观测到的 JS 堆峰值约 14.1 MiB，隔离测试浏览器进程工作集采样峰值约 804 MiB。采样请求间隔 500 ms，含端点，进程采样会影响耗时；工作集包含浏览器进程，并非扩展独占内存，也不保证捕获绝对峰值。不能据此推广到任意视频、硬件或商店版本。

原始记录：`.output/media-performance/result.json`；复现脚本 `scripts/measure-media.mjs`，需先准备对应素材并运行预览服务。
