# 数据操作契约

> 状态：已确认，作为工程与数据层的实现依据。视觉与交互见 [VISUAL-SPEC.md](./VISUAL-SPEC.md)。
> 本契约定义规范，不作为实现完成清单。当前代码为 Dexie 数据库版本 12、ZIP 备份 formatVersion 9、同步快照 schema 11；显式接收并升级当前 Beta 2 的 Dexie 11、ZIP 8 和同步 10，不接受旧分组/Beta 1 格式。§11 描述同步边界。实现状态见 [TASKS.md](./TASKS.md)，验证范围见 [VERIFICATION.md](./VERIFICATION.md)。

## 1. 数据实体

WebDAV 远端库永久删除需用户二次确认：删除当前库的描述、设备快照和图片；本机领域数据保留，已连接时成功后移除本机连接与同步密钥。忘记恢复密钥时，允许通过检查成功的 WebDAV 凭据确认删除已有远端库，无法恢复旧密文内容；目标变化时拒绝删除，不自动创建替代库。删除范围、并发和部分失败规则见 [SYNC-WEBDAV.md](./SYNC-WEBDAV.md)。

### 1.1 快捷方式（shortcut）

| 字段 | 说明 |
|---|---|
| id | 稳定唯一标识，创建后不变；用于排序、引用与未来同步 |
| folderId | 可空；null 表示主页网格，非空时属于一层文件夹 |
| title | 普通文本标题，≤80 字素簇 |
| url | 已校验并规范化的 http/https 地址 |
| icon | 图标引用（文字首字母 / 六种内置图形 ID / 本地资源 id），含可选 `occupancy` 占比和 SVG 专用可选 `color` |
| iconSourceUrl | 可选，外链下载的来源 URL；随备份导出 |
| order | 主页网格或文件夹内排序位置 |

### 1.2 文件夹（folder）

| 字段 | 说明 |
|---|---|
| id | 稳定唯一标识 |
| name | ≤40 字素簇，允许重名，以 id 区分 |
| order | 主页网格内的文件夹排序位置 |

主页网站与文件夹格子平铺在同一个网格。网站默认 `folderId: null`；用户主动移入文件夹后记录该 folderId。文件夹只能一层、不允许嵌套。
### 1.3 设置（settings）

- 外观：主题模式、背景引用（默认/纯色/渐变/静态照片/动态媒体）、动态色开关、配色模式与手动种子色、背景遮罩强度。
- 搜索：默认引擎引用、自定义引擎列表、搜索框宽度、主页启动时自动聚焦及提交后的打开方式；`customization` 保存圆角、背景不透明度、提示文字、网站/文件夹来源、工具启停及引擎关键词，详见 [SEARCH-DESIGN.md](./SEARCH-DESIGN.md)。新增配置使用独立同步寄存器。联网搜索建议不属于 MVP。
- 快捷方式：网站名称显示与网站链接打开方式。
- 布局：`style` 排布样式、`order` 顺序数组、`hidden` 隐藏集合、页面宽度、区域间距和网站网格最大列数（见 §4）。
- 时钟：系统 / 12h / 24h 时间制、字号、秒数/日期/星期显隐，以及日期和星期格式。日期支持本地化月日、本地化年月日和按本地日历生成的 `YYYY-MM-DD`；日期与星期可独立隐藏。
- 星期格式为完整本地名称、系统语言简写或固定英文 `Mon`、`Tue`、`Wed`、`Thu`、`Fri`、`Sat`、`Sun`，默认完整本地名称。

### 1.4 资源（asset）

图标与背景的本地二进制，记录 kind、尺寸、最终 MIME 与可选来源 URL。MP4、WebM、GIF 与动画 WebP 只可作为本地动态背景上传；原始媒体保存在资源 Blob 中。动态媒体的 poster 为可重新生成的本地 PNG 缓存，不参与备份或同步。结构化配置只保存资源引用，不内联二进制。

## 2. 校验规则

### 2.1 地址（url）

- 仅接受 `http:` 与 `https:`；拒绝 `javascript:`、`data:`、`file:` 等。
- 去除首尾空白；缺少 scheme 时补 `https://`。
- 解析后要求：协议为 http/https、存在主机名、不含用户名或密码。
- 保留路径、查询参数与片段，不改写用户输入。
- 长度 ≤2048 个 Unicode 字符。

### 2.2 名称

- 标题 ≤80 字素簇、文件夹名与引擎名 ≤40 字素簇。
- 去除首尾空白并拒绝控制字符；按 Unicode 字素簇计数。网站标题允许留空并显示域名；文件夹名与引擎名不可为空。
- 普通文本，不支持 HTML 或 Markdown。文件夹与网站均可重名，以 id 区分。

### 2.3 重复地址

允许完全重复的地址，主页或文件夹内/之间均可；每条独立记录、独立标题与图标，不做隐式合并或去重。

### 2.4 搜索引擎

- 内置引擎只可选择，不可编辑或删除；默认指向 Google。
- 自定义引擎可增删改，仅接受 HTTPS 模板。
- 模板必须恰好包含一个 `{query}`，且只能出现在查询参数的值中（不得出现在协议、主机或路径里）；提交时对查询内容做 URL 编码。
- 删除当前默认引擎前必须先指定另一个有效引擎；不允许删除最后一个可用引擎。
- 引擎关键词独立保存，大小写不敏感唯一，不得与 `gh` 等工具语法冲突；仅路由当前查询，不改默认引擎。删除自定义引擎时同事务清除其关键词。

### 2.5 颜色

以下规则针对持久化的外观颜色；搜索颜色工具接受 HEX/RGB/HSL 及透明度，仅产生预览和复制结果，不隐式写入外观设置。

- 颜色一律保存为小写 `#rrggbb`；不接受三位简写、`rgb()` / `hsl()` 写法或带透明度的值。
- 取色面板内部的 HSV、色相与滑块位置都是界面状态，不落库：写回的始终是 `#rrggbb`。
- 屏幕吸管返回的 `sRGBHex` 在写入前同样规范成小写 `#rrggbb`。
- 十六进制输入在构成合法颜色前不写入；非法输入只标记该输入无效，不回滚用户已选定的颜色，也不清空设置。

### 2.6 网站图标占比

- `ShortcutIcon.occupancy` 为可选整数百分比，范围 50–100、步长 1；省略时按 75% 显示。主页外框固定 48px，编辑预览外框固定 64px。两处以外框内可绘制区域为基准应用相同占比；预览只扣除 1px 边框，不再额外缩小图案。
- 默认值 75% 采用规范形式：序列化时省略 `occupancy`；显式值只保存用户偏离默认后的选择。没有该字段的记录按当前默认 75% 显示。
- Dexie 版本 4 已把旧版 `ShortcutIcon.size` 像素值换算为 `round(size / 48 * 100)` 并限制在 50–100%，同时迁移本地同步寄存器；当前数据库版本为 12。旧尺寸大于 48px 时归一化为 100%；换算结果正好 75% 时按新默认值省略。
- 历史 Dexie 5–8 曾迁移布局与唯一分组名称偏好；这些不是当前旧分组库的兼容承诺。当前 Dexie 12 拒绝旧分组数据，不自动转换或清空本地领域数据、同步身份/密钥及远端库；用户可主动卸载重装。当前设置不包含唯一分组名称偏好。
- 占比与图标类型/资源引用共同构成图标原子字段，在同步中使用同一字段寄存器合并；不把占比拆成独立冲突字段。
- 占比改变只影响固定外框中的图案显示，不修改图片 Blob。编辑表单中的实时预览是透明底草稿，外框用细边框标识；取消不保存，保存时与网站数据一起写入。
- `ShortcutIcon.color` 是可选的小写 `#rrggbb` 单色覆盖，只能用于引用 `image/svg+xml` 资源的 asset 图标；省略时显示 SVG 原色。设置颜色后通过本地 CSS mask 整体单色渲染，清除颜色恢复原色。PNG/WebP、文字/内置图标和背景不接受该字段。
- 图标类型、资源 ID、占比和颜色共同属于 `icon` 原子寄存器，作为一个字段合并；颜色不能与 SVG 资源分离或独立胜出。

## 3. 文件夹生命周期

- 网站默认直接放在主页网格，`folderId: null`；用户可选创建文件夹并将网站移入。
- 文件夹仅一层，不支持嵌套。名称规范化后允许重复，以 id 区分。
- 文件夹是主页网格中独立格子，点击后用弹层显示其网站；主页没有分组/文件夹标签行。
- 删除文件夹需二次确认。删除时同一事务把其中网站按文件夹内顺序追加回主页网格，不删除网站或图标。
- 网站可以在主页与文件夹之间移动；网站在当前容器中排序位置连续。
- ZIP 当前格式严格要求 `folders` 和 `folderId`。包含旧 `groups`/`groupId` 的 ZIP 拒绝；不猜测多个旧分组应如何折叠为一层文件夹。

## 4. 布局插槽模型

- 固定三个命名区域：`clock`、`search`、`shortcuts`；`shortcuts` 在主页网格中平铺文件夹格子和主页网站。
- `style` 仅允许 `centered`（居中留白）、`top-search`（顶部工作台）、`left-stack`（左侧锚点）、`split`（左右分区）。沿用前三个标识，不重写既有布局数据；split 首次实现于 Dexie 11 / ZIP 8 / sync 10，当前搜索升级使用 Dexie 12 / ZIP 9 / sync 11，旧客户端不识别时明确拒绝，不承诺向下兼容。模板切换只改 style，不重置列数、宽度、顺序、显隐或网站数据；`hidden` 隐藏整个 shortcuts 区域。
- 页面宽度、区域间距和网站网格最大列数控制文件夹与网站共用的网格。
- 布局无“唯一分组名称”偏好；不保存或同步 `hideGroupNameWhenSingle`。

## 5. 图片与资源规则

### 5.1 可接受格式

静态图片支持 JPEG、PNG、WebP，以及受限静态 SVG。动态壁纸支持 MP4、WebM、GIF 和动画 WebP，仅允许本地文件上传；真实内容签名和浏览器解码均须有效。SVG 只在满足安全子集时被接受；照片背景中的 SVG 在本地栅格化，静态 SVG 图标保留为本地 SVG。

### 5.2 安全 SVG 子集

- 必须为静态 SVG：拒绝脚本、`foreignObject`、事件属性、外部引用/字体与外部样式表。`url(#id)` 仅允许引用同一文件内的已验证资源，不允许外部 URL、data URL、CSS 变量或转义。
- 元素与属性只允许 `src/platform/svg.ts` 的显式白名单。允许 SVG/XLink 命名空间声明；`xlink:href` 仅支持内部引用并归一化为 `href`，两者同时存在时必须一致。允许 XML `xml:space` 属性，值仅接受 `default` 或 `preserve`；其他 namespace 属性拒绝。
- 允许几何元素和静态资源元素：`svg`、`g`、`path`、`rect`、`circle`、`ellipse`、`line`、`polyline`、`polygon`、`title`、`desc`，以及 `defs`、`linearGradient`、`radialGradient`、`stop`、`clipPath`、`mask`、`pattern`、`use`、`symbol`、`style`。完整属性白名单见 `src/platform/svg.ts`；新增渐变、蒙版、裁剪、平铺图案、id/class 及内部引用属性。资源引用检查目标存在、唯一、类型匹配及无循环；不下载依赖资源。
- 内联 `style` 支持 `src/platform/svg-style.ts` 列出的静态展示属性，完整解析并按浏览器 CSS 值语法检查后转换为展示属性；重复声明与 `!important` 保持原优先级。根节点另接受并保留 `flex:none`、`line-height:1`。不支持的声明、CSS 注释、转义或动态变量明确报错，不丢弃未知样式。
- 内嵌 `style` 样式表（可声明 `type="text/css"`）支持简单元素/class/id 选择器、同一元素的组合选择器及逗号列表。先解析全部规则，再按 important、内联优先级、选择器权重和声明顺序转换为属性，移除已完整转换的样式表。媒体查询、伪类、组合器、外部样式、嵌套规则及其他未支持语法明确拒绝；不是通用 CSS 引擎。
- 根节点正数 `em`、`rem`、百分比尺寸必须提供有效 `viewBox`，按对应 viewBox 宽高归一化；不依赖宿主页字体或容器尺寸。缺少有效 viewBox 时明确失败。数值与 px 尺寸规则保留。
- 拒绝 DTD、实体声明和非 XML 声明的处理指令；属性值不接受 `url()`、反斜线或控制字符。
- SVG 原文件 ≤10 MiB；需要栅格化时输出 ≤1024×1024 且 ≤4 MP。保留的 SVG 图标不经画布转换。
- 背景 SVG 在本地画布栅格化为 PNG；图标 SVG 通过同一白名单后规范化为 `image/svg+xml`：显式设置最长边不超过 1024 的宽高；缺少 `viewBox` 时按原尺寸补 `0 0 <width> <height>`，再由 XMLSerializer 序列化。保留白名单内的矢量几何与展示属性，不保证原字节相同。无法可靠安全处理时明确报错，提示改用 PNG/WebP。

### 5.3 尺寸与体积

| 类别 | 原文件 | 像素 | 输出 |
|---|---|---|---|
| 用户照片背景 | ≤10 MiB | ≤40 MP | 最长边 ≤2560 px，输出 JPEG/WebP（安全静态 SVG 与静态 PNG 也栅格化为 PNG） |
| 网站图标 | ≤10 MiB | ≤4 MP | 最长边 ≤1024 px；栅格图片转静态 PNG，安全 SVG 图标保留为 `image/svg+xml` |
| 动态壁纸 | 不设应用级单文件大小或时长上限 | 不施加静态图片像素上限 | 保存 MP4/WebM/GIF/动画 WebP 原件；浏览器解码或 IndexedDB 配额失败时明确报错 |

- 动态 WebP 作为动态背景保留多帧原件；网站图标只允许静态图片。动态背景启动、导入和同步接收均校验内容签名及浏览器解码能力；不自动转码。
- 本地上传与直链下载的 SVG 图标采用同一严格白名单校验并以 `image/svg+xml` 本地保存；照片背景中的 SVG 通过相同校验后栅格化为 PNG。MIME 必须与内容匹配；领域、存储、ZIP 备份和同步接收均校验资源 MIME 与图标引用类型。
- 不再设置 50 MiB 本地媒体总量上限。存储空间由浏览器配额决定；配额不足、写入失败或解码资源不足时明确报告实际错误，不静默缩小、转码或丢弃素材。

### 5.4 图标来源

四类：文字/首字母、内置基础图形、本地上传、图片直链下载到本地。不按网站地址自动抓取 favicon，渲染时不加载远程图标。

### 5.5 图标直链下载

- 网站图标编辑的 URL 栏旁提供 Dashboard Icons 外链；不内置目录、不调用接口，用户自行复制链接并主动保存。
- 用户也可主动提供例如 `https://cdn.jsdelivr.net/gh/selfhst/icons/svg/x.svg` 的静态 SVG 直链；不会自动重新下载既有图标，只有用户重新选择并下载 SVG 后才能使用 SVG 单色功能。既有 PNG 位图不能转换回矢量。
- 接受任意公网 HTTPS 主机；HTTP 仅允许主机名严格等于 `localhost`。
- 拒绝明显本机/回环 IP 与内网主机名（尽力校验，见 §9 限制）。每次请求均阻止浏览器自动跟随重定向；读取响应的跳转地址后，重新校验协议、主机及凭据。通过校验的同来源跳转可继续；跨来源时先展示目标，用户再次点击后才对该来源申请权限并请求，循环跳转明确报错。
- 拒绝含用户名或密码的 URL；保留查询参数。成功下载的来源 URL 随图标写入本机与备份。
- Manifest 声明 `optional_host_permissions`（`https://*/*`、`http://localhost/*`）及可选 `webRequest` 权限，仅在用户点击下载时同时请求具体来源及读取响应头的权限；不安装时授予全部站点访问。响应头监听只在该次请求期间注册，过滤当前链接和扩展自身发出的 GET 请求，结束后移除，不常驻观察浏览活动。同一链接的请求通过原生独占锁串行，避免把并行请求的跳转地址混用。
- 用户取消或拒绝权限即不下载；失败或 CORS 不允许时保留当前图标并提示改用本地上传，不退化为后台代理。
- 图片 URL 使用“自定义图片URL”标签与右侧下载图标按钮；跨来源跳转时仍须先展示目标并由用户再次点击继续，错误时保留已选图标和输入内容。删除重复的保存说明，不新增 cookie/provider 确认弹窗。
- 下载成功后本地化保存；实际下载完成的已批准来源 URL 写入记录，界面可提供来源链接，不保存许可字段。
- 再次打开图片设置时回填已保存来源，只有用户点击下载才更新本地图片；显示、刷新和回填均不发网络请求。输入新地址未下载/保存时仍是界面草稿，不给当前本地图片改写来源。
- 网站图标编辑以所引用资源的实际来源回填，保存时同步网站来源字段；已有资源保留来源但网站字段为空的记录也可读取。清除来源成功后输入同步清空，保留图片和其他未保存字段；异步读取不能覆盖用户正在输入的地址。
- 上传图标按钮与首字、内置图标选择按钮同行；主页图标外框固定 48px，图案占比滑块为 50–100%、步长 1%、默认 75%，编辑预览为固定 64px、透明底和细边框。取消编辑不写入，保存/刷新、ZIP 备份和加密同步均携带该设置。

### 5.6 资源清理

- 网站图标按引用关系清理：不再被任何网站引用的图标资源及其来源元数据一并删除。
- `kind=background` 的照片、GIF、动态 WebP、MP4 与 WebM 属于本地壁纸素材库。切换当前背景不删除资源；用户显式删除时在同一事务中移除原件，并为已启用同步的库产生永久删除墓碑。
- 删除当前壁纸时，同一事务把背景设为默认中性渐变并删除原件。用户也可以先应用其他库内壁纸，再删除原素材。
- 手动仅清除来源时只删元数据，保留已下载的本地 PNG。

## 6. 备份格式与流程

### 6.1 内容

- ZIP manifest v8 保存 `folders`、`shortcuts`（每条含 `folderId`，null 表示主页）、设置和媒体元数据；assets 目录保存原始媒体。
- ZIP 不包含权限、临时界面状态、poster 缓存、同步元数据、恢复密钥、CryptoKey 或提供方凭据。

### 6.2 上限

- 文件夹 ≤50、网站 ≤1000、自定义引擎 ≤20；新增与导入遵守相同上限。
- 不设置 ZIP 文件大小、媒体总量或视频时长的产品级限制；底层容量/解码失败必须明确显示。

### 6.3 导出与导入

- 导出单个 ZIP；先校验并生成完整一致快照。任何资源读取、摘要计算或 ZIP 失败都中止。
- 导入 ZIP v9 或显式升级的文件夹格式 v8 前完整校验路径、CRC、SHA-256、领域字段、folder 引用与媒体内容；确认后在单一 IndexedDB 事务完整替换。
- `groups`/`groupId` 旧 ZIP v2–7 均拒绝，因为无法安全推断各分组应映射为主页网站还是文件夹。开发期 JSON 与 Beta 1 ZIP v1 也拒绝；拒绝不清空本机或远端数据。
- 备份导入不联网重取来源图片、不授予来源权限；同步已启用时按新的 folder/shortcut 实体规则防止标识复活。

## 7. 编辑、删除与重置

- 网站与文件夹在主页网格管理。网站菜单提供编辑、顺序移动、移入文件夹、移回主页和删除；文件夹菜单提供打开、重命名与删除。
- 文件夹弹层显示其网站，添加网站默认进入该文件夹；单条删除在当前会话提供 5 秒撤销，跨容器恢复失败时明确报错。
- 文件夹删除需二次确认，提示网站返回主页；不会整文件夹级联删除网站。
- 重置本地数据二次确认后清空网站、文件夹、背景与设置，恢复默认外观和搜索配置；不删除扩展、不清理浏览器授权。若同步已配置，重置会按同步墓碑规则传播相应数据删除。

## 8. 搜索建议（MVP 不提供）

MVP 不请求联网建议，不存储查询历史；只在用户提交时打开所选搜索引擎。重新纳入该功能需要重新确定服务、外发查询授权与密钥方案，依据见 [DECISIONS.md](./DECISIONS.md)。搜索文件夹建议由本地用户主动选择后打开文件夹弹层。

## 9. 已知限制（如实记录）

- Manifest V3 扩展无法可靠判断任意域名最终解析出的 IP，故“拒绝内网地址”只能尽力校验，无法绝对排除私有 DNS 映射。
- 扩展无法直接读取操作系统壁纸或系统强调色；动态取色的来源是扩展自身当前背景。
- 联网搜索建议按产品决策排除在 MVP 外；只有重新决定纳入时，才启动服务与权限核验。
- 屏幕吸管依赖 `EyeDropper` API（仅 Chromium 系提供）。界面按能力探测决定是否显示入口；2026-10-14 用户确认屏幕吸管验收完成，依据见 [VERIFICATION.md](./VERIFICATION.md)，未另提供取色/取消/能力不可用分项记录。自动化测试只覆盖能力探测、用户取消与其他失败的分类。
- 颜色只保存 `#rrggbb`，色相不单独存储：当饱和度为 0 或明度为 0 时，色相无法从颜色本身还原，重新打开取色面板时色相由颜色反推。面板展开期间会保留用户当前色相，收起再打开则会归零。

## 10. 默认值

| 事项 | 默认 |
|---|---|
| 初始网站与文件夹 | 主页为空；网站直接进入主页网格；不预置文件夹或示例网站 |
| 时钟 | 跟随系统区域设置 |
| 搜索引擎 | Google |
| 搜索建议 | MVP 不联网；本地网站/文件夹建议可用 |
| 搜索个性化 | 标准宽度；自动聚焦关闭；提交后在当前页打开 |
| 搜索框与工具 | 标准圆角、自动背景不透明度、提示“搜索、查找网站或计算”；网站/文件夹及四类工具均启用；引擎关键词为空 |
| 网站个性化 | 名称显示；点击后在当前页打开 |
| 主题 | 跟随系统 |
| 动态色 | 开启，跟随当前背景 |
| 背景 | 中性渐变；照片可上传或主动下载，动态媒体本地上传 |
| 图标 | 文字/首字母 |

## 11. 跨设备同步（基础层、协调器与 WebDAV 已实现）

- 同步文件夹、快捷方式、设置、静态照片、动态媒体和图标；保持现有 UUID，不将媒体 Blob 放入结构化记录。
- Dexie 是本地工作数据源。HTTPS WebDAV 与 S3 兼容存储用于保存加密的每设备快照和独立媒体对象；Cloudflare R2 为首个 S3 实际验收目标，Google Drive 适配器延期。一个同步库一次只使用一个提供方，Chrome storage.sync 不承载数据。
- 新建同步库的一次性恢复密钥可由用户主动复制到系统剪贴板；不自动复制或读取剪贴板，也不因此自动确认已保存。扩展不新增密钥正文的持久化，复制失败明确显示。
- 同步状态、设备身份、字段级逻辑版本、删除墓碑和本地 CryptoKey 存放在独立 Dexie 表，不进入用户可见领域记录或 ZIP 备份。
- 字段级冲突以 Lamport 逻辑时钟及设备 ID 确定胜者；同 ID 删除墓碑永久保留且 ID 不复用。文件夹删除不产生网站级联墓碑；接收时仍指向已删文件夹的网站派生到主页，不改写 placement 寄存器、clock 或 deviceId。物化顺序不伪造用户编辑。
- 当前同步快照 schema 11 使用文件夹及 `folderId` placement，包含完整壁纸库、素材名称、永久删除墓碑和独立 `searchCustomization`；严格验证 schema 10 后显式补零时钟的新寄存器。旧 schema 1–9 明确拒绝，不自动清理本地数据/同步身份或删除远端；旧客户端不支持当前格式。
- `ShortcutIcon.occupancy` 与 SVG 专用 `color` 属于同一原子字段寄存器。schema 10/11 的动态媒体元数据不包含 poster；poster 在接收端由已验证原始媒体重建并只存本机缓存。布局样式、时钟角落与区域设置共同处于 `layout` 原子寄存器中；素材名称是独立的 `name` 寄存器，不影响媒体身份。
- 每设备快照和每项媒体原件均使用 AES-256-GCM 端到端加密，媒体逐文件加密。WebDAV 的 `vault.json` 与 S3/R2 的 prefix 描述只含版本、vaultId 和库描述密文；每设备快照和媒体保持独立对象。恢复密钥为本地随机生成的 256-bit 密钥，用户保存并手动带到新设备；密钥和提供方凭据不上传。
- 首次连接先合并，不静默覆盖本地用户数据。无效远端数据不得部分应用；候选和媒体完整校验后，通过单一 IndexedDB 事务提交。随后发布失败保留完整本机合并和新编辑，明确失败/待同步，不伪造跨本机与远端的原子回滚。
- sync_state 的本机基线、运行 ID/阶段/发布确认和最近成功记录不进入快照或 ZIP 备份。完整接收后记住首次合并基线，即使发布失败也不重复提升旧字段；断开/重连后的旧运行不改新连接状态。
- 用户未启用同步时，扩展不连接同步服务。WebDAV 凭据只保存在当前 Chrome 配置文件 `chrome.storage.local`，其访问级别限制为 `TRUSTED_CONTEXTS`；需要的 `storage` 为扩展权限，HTTPS 主机访问保持 optional，并仅请求配置 origin。凭据不进入 Dexie、快照或 ZIP 备份。
- 启用后，扩展页打开、本机 generation 写入和撤销截止期限的单次 timer 可触发异步同步；没有定时轮询和自动重试。扩展页关闭可能中断任务，下一次打开或手动操作恢复。基础协议见 [SYNC-PROTOCOL.md](./SYNC-PROTOCOL.md)，协调流程见 [SYNC-COORDINATOR.md](./SYNC-COORDINATOR.md)，受控服务审计见 [SYNC-WEBDAV.md](./SYNC-WEBDAV.md)。Drive、设备集合、远端清理及密钥轮换仍需实施。
