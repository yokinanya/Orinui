# 文档索引

本目录保存 Orinui 的产品与设计文档。

| 文档 | 内容 |
|---|---|
| [PROJECT.md](./PROJECT.md) | 项目背景、产品定位、核心需求、技术栈建议与开发原则 |
| [ARCHITECTURE.md](./ARCHITECTURE.md) | 工具链选择、目录职责、设计令牌、平台边界与已记录的偏差 |
| [VISUAL-SPEC.md](./VISUAL-SPEC.md) | 已确认的视觉规格：页面构成、颜色与主题、字体层次、固定插槽、搜索与焦点、动效与无障碍 |
| [DATA-CONTRACT.md](./DATA-CONTRACT.md) | 已确认的数据契约：数据模型、校验规则、分组生命周期、图片与资源规则、备份格式、额度上限与默认值 |

## 阅读顺序

1. 先读 PROJECT.md 了解定位与边界。
2. 再读 VISUAL-SPEC.md 了解界面形态与交互。
3. 实现数据层或备份功能前，必须先读 DATA-CONTRACT.md。
4. 修改工程配置或目录结构前，先读 ARCHITECTURE.md。

## 约定

- 文档描述“已确认的决策”，未决事项会明确标注为待确认或已知限制。
- 修改实现后需同步更新对应文档，保持文档与代码一致。
