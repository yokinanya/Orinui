# Orinui 0.1.0-beta.1

Orinui 是本地优先的 Chrome 新标签页扩展，提供时钟、搜索、网站分组、外观定制和可选的端到端加密 WebDAV 同步。项目不要求 Orinui 账号，不含广告或追踪。

## Beta 新增

- 动态壁纸接受本地 MP4、WebM、GIF 和动画 WebP；视频静音循环，不播放音频。
- ZIP 备份包含配置、资源清单和原始图片/动态图像/视频，默认不加密。
- 动态媒体随 WebDAV 同步时逐文件端到端加密。
- 首个 Beta 建立新的备份与同步格式基线，不导入开发期 JSON 备份或开发期同步快照。

## 下载与安装

从本页 Assets 下载 `orinui-0.1.0-beta.1-chrome.zip` 和 `.sha256` 校验文件。GitHub 自动生成的 Source code 压缩包是源码，不能直接加载为扩展。

解压到固定目录，打开 `chrome://extensions` 并启用“开发者模式”，选择“加载已解压的扩展程序”，再选中解压后的扩展目录。后续更新前导出 ZIP 备份；解压新版并覆盖同一目录，在扩展管理页点击“重新加载”。移动目录可能会导致 Chrome 将扩展识别为新安装。

## 数据与隐私

- 本机网站、分组、设置和媒体存储在浏览器本地数据库中。搜索内容仅在用户提交时发送给所选搜索引擎。
- 图片直链下载和 WebDAV 访问需要用户主动操作；扩展按操作请求可选来源权限。新标签页显示背景时不下载远程内容。
- WebDAV 登录凭据存于当前 Chrome 配置文件的本地扩展存储。远端数据由端到端加密保护；ZIP 备份不包含凭据、恢复密钥或同步运行状态。
- ZIP 备份默认不加密。请把备份视为包含完整个人数据的文件并自行妥善保管。

## 已知限制与验证

- 首个 Beta 不兼容开发期 JSON 备份与开发期同步快照。导入或同步发现不支持的格式时应显示明确错误，不会为了兼容而自动清除本机或远端数据。
- 动态媒体依赖当前 Chrome 对具体文件编码的解码能力；不支持的编码会报告错误，不自动转码。
- 类型检查、413 项单元/集成测试、87 项完整 Chrome 网页回归、生产构建和 ZIP 打包通过；独立干净副本按锁文件安装后编译、测试和构建通过。
- 隔离真实扩展的受控 HTTPS WebDAV 双配置检查验证了 WebM、GIF 和 34.1 MiB MP4 的加密同步、封面重建及播放；第三个离线配置完成 ZIP 恢复。来源预授权，未覆盖新增媒体在真实第三方服务上的全部组合或权限弹窗。
- 后台暂停的真实可见性事件专项尚未验收：自动化 Chromium 切换标签页后仍报告页面可见；不把该专项记为通过。
- 本机 12 秒 1080p MP4（34.1 MiB）导入约 1.7 秒、ZIP 导出约 1.6 秒、恢复约 1.8 秒；仅代表本机普通网页预览采样。完整读屏器、更多媒体/设备组合、商店性能验收和 Chrome Web Store 发布尚未完成。
