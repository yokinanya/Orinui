## 设计复审（2026-10-17）

用户要求重新通读界面。以已确认的 UI 验收为基线，在 Chrome 普通网页预览中检查空状态、明暗主题、设置五个分区、375/320px、搜索建议、编辑模式与网站弹窗，并对照 [VISUAL-SPEC.md](./VISUAL-SPEC.md)。实测与代码对照发现并修复以下问题：

| 问题 | 表现与依据 | 处理 |
|---|---|---|
| 空名称无法保存 | 网站名称必填；名称清空时列表出现无文字格子、首字母图标显示「?」，与凭据类字段的留空规则不一致 | 空名称显示地址域名，图标取域名首字母；输入框提示「留空时显示网站域名。」 |
| 网格列宽不均 | `auto-fit` 折行与行内声明的轨道数不一致，窄屏只剩 19–27px 的列；长名称把列撑宽 | 全量声明列轨道、最小格子宽度与网格横向滚动；名称在格子内省略 |
| 编辑模式空停靠点 | 空分组时编辑模式下第一个 Tab 停靠点是无名称的可拖动区域 | 拖动入口移出 Tab 序列，保留「⋯」操作入口；空分组提供「编辑分组」 |
| 隐藏唯一分组名后无入口 | 标签行不显示时，无法通过键盘或菜单重命名唯一分组 | 分组栏提供「分组操作」菜单 |
| 弹窗偏离中心 | 主页入场动效与 dnd transform 在祖先上，弹窗的 fixed 居中相对祖先盒子计算 | 改用 fixed 居中包装层，弹窗自身只做透明度动画 |
| 双重焦点描边 | 网站/添加格子/分组标签同时有统一轮廓与 `ring` 阴影 | 保留带底色的统一焦点轮廓，移除第二层 ring |
| 提示条遮挡操作入口 | 删除撤销提示条覆盖右下角设置/编辑按钮 | 提示条上移，保留层叠与展开动画；关闭按钮改为「关闭提示」 |
| 照片分组标签 | 照片壁纸上的分组标签只有描边、没有柔光，与时钟/日期处理不一致 | 补上统一的文字阴影变量 |
| 强反差渐变上次级文字 | 黑到白渐变上网站名称 4.364:1 | 非照片背景的次级文字由 `#514b45` 加深为 `#3d3833`，复测 ≥ 4.5:1 |

## 环境与方法

- 先用 Chrome HTTP 预览排查，再用本机已有的 Chromium 153.0.8010.12 加载 `.output/chrome-mv3`，所有最终截图与测量来自真实 `chrome-extension://` 页面。
- 使用独立临时浏览器配置；展示数据通过实际 JSON 导入界面写入该配置，包含 5 个分组、24 个网站、长名称与内置图标。没有写入用户 Chrome 配置或初始示例数据。
- 记录空状态、明暗主题、编辑模式、键盘菜单、设置五个分区、取色弹层，以及 1440/768/640/375/320 CSS px 视口。网站编辑对话框另检查 375×667、320×800、1366×768、640×450。
- 1280×900 视窗调用真实浏览器缩放到 200%，实测 `innerWidth=640`、`innerHeight=450`、`devicePixelRatio=2`。Chrome 内部 `chrome://newtab` 不允许该 API；缩放检查直接访问同一真实扩展页面。
- 对比度使用浏览器计算后的名义文字 RGB，与隐藏内容后背景截图的对应中心像素计算；组标签另外采样实际胶囊底色。该采样可证明反例，不代表全部图片、焦点环或控件都已满足 WCAG。
- 普通文本按 4.5:1、大号时钟按 3:1 检查，依据 [WCAG 2.2 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。代码审查参照 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)。
