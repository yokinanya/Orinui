# Chrome 新标签页扩展项目

## 项目背景
计划开发一款 Chrome 新标签页扩展，作为 MONKNOW 的替代品，并考虑公开发布到 Chrome Web Store。

开发者已有 Chrome 开发者账号。

## 产品定位
一款设计精致、轻量、注重隐私、无广告和推广内容的新标签页扩展。

**设计美观是第一优先级。** 不需要复刻 MONKNOW 的布局，可以探索更现代的视觉设计。

## 参考产品
- MONKNOW：网站图标管理、分组、云同步
- Bonjourr：极简主义、沉浸式壁纸、精致的视觉设计
- Tabliss：大幅背景、自由组合组件
- nightTab：布局和主题的高度自定义

## 核心需求
1. 现代、美观、易用的界面
2. 搜索、时钟、常用网站及分组管理
3. 自定义背景、图标、主题和布局
4. 流畅、克制的界面动画
5. 本地优先，支持离线使用
6. JSON 数据导入导出
7. 最好支持 Chrome Sync
8. 不包含广告、推广和追踪

## 技术栈建议
- WXT + React + TypeScript
- Tailwind CSS v4 + shadcn/ui
- Motion
- Zustand
- IndexedDB / Dexie
- Chrome Manifest V3

技术选型可以根据实际需要调整。

## 开发原则
- 性能优先，尽可能减少新标签页打开延迟
- 最小化浏览器权限
- 模块化设计，便于未来扩展
- 不强制注册账号
- 预留开源与 Chrome Web Store 发布的可能性
