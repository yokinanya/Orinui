# Orinui

设计精致、轻量、本地优先的 Chrome 新标签页扩展。无 Orinui 账号、无广告、无追踪。

## 已实现功能

- **WebDAV 远端删除**：已连接面板支持删除整个远端同步库，保留本机数据并断开；留空恢复密钥检查出已有库时，可通过“忘记恢复密钥？”二次确认删除云端库后重新建库。删除不可撤销，需先停止其他设备同步；真实服务删除兼容性待验收。

- **主页与管理**：时钟、搜索、网站与一层文件夹在主页同一网格平铺，文件夹与网站分别排序；不提供分组标签行、主页导航栏或侧栏。网站 `folderId: null` 表示主页；文件夹弹层显示其网站，删除文件夹将网站返回主页。右键菜单、编辑模式、排序和网站移入/移出文件夹在主页完成。网站名称可隐藏并保留可访问名称，网站链接可在当前页或新标签页打开。
- **外观**：系统/浅色/深色主题，中性渐变、纯色、渐变、照片背景，照片遮罩，本机动态配色，自建取色面板与屏幕吸管入口。主页可选居中纵排、顶部搜索和左上纵排；顶部搜索的时钟可放在左上角或右上角，不再提供唯一分组名称选项，三种布局共用主题与背景可读性规则。
- **壁纸素材库（Beta 2）**：照片、GIF、动态 WebP、MP4 和 WebM 保留在本机库；选中素材只更新较大的详情预览，点击“应用”后才切换背景，删除当前壁纸时确认后切回默认渐变。视频静音循环，暂停时保留当前画面并从暂停位置续播；其格式、尺寸与原件大小随素材显示。
- **图片**：本地照片和图标上传、严格白名单 SVG 处理与尺寸/体积校验；照片 SVG 栅格化，安全图标 SVG 规范化后保留矢量并可选单色；主页图标外框固定 48px，可调内容占比 50–100%（默认 75%）；图片链接回填后可手动更新，同来源重定向继续、跨来源再次确认；内置图标使用图形选择器，透明底预览带边框。页面只读本地图片，不自动抓取 favicon。
- **搜索与快捷工具**：四区搜索设置、圆角/背景不透明度/提示文字、独立结果来源和工具开关；预置与自定义引擎均可编辑名称/HTTPS 模板和关键词，预置引擎可恢复默认。单次引擎关键词、网址打开、本地中文/全拼/首拼检索。保留计算与单位换算，新增带透明通道的颜色格式、WCAG 对比度、时间戳、日期加减/差值与时区转换。GitHub 仓库、Issue/PR、搜索、完整 Releases 和克隆命令统一通过 `gh`；裸写 `owner/repo#123` 为普通查询。输入期间不联网、不保存查询历史、不读取剪贴板；详见 [搜索设计](./docs/SEARCH-DESIGN.md)。
- **时钟与布局**：时钟可设置大小、秒数、日期与星期格式和显隐；顶部搜索布局可调时钟角落；页面宽度、区域间距、主页区域显隐与居中布局排序可配置。
- **本地数据**：Dexie 数据库版本 13、跨表事务、ZIP-only formatVersion 10 完整备份与恢复；显式升级上一版及 Beta 2 文件夹格式，不迁移旧分组格式；拒绝时保留既有数据与同步身份。ZIP 包含全部壁纸素材原件。

设置以轻边框分区组织主题、布局和背景的可视选项；壁纸库与自定义搜索引擎编辑使用面板内二级页及返回入口。网站编辑提供实时预览，“保存并继续添加”保留目标文件夹并清空本条内容。这些是本轮实现范围，不是验收结论。

## 首个 Beta 功能基线（历史）

- 动态壁纸支持 MP4、WebM、GIF 和动画 WebP，通过本地文件上传；视频静音循环播放。新标签页仍先显示本地主页，不等待媒体解码，渲染不发起网络请求。
- 完整备份采用 ZIP：`manifest.json` 保存配置和资源元数据，`assets/` 保存原始媒体。ZIP 默认不加密，且不会导入开发期 JSON 格式。
- WebDAV 对动态媒体按文件端到端加密。新版同步格式不兼容开发期快照；格式错误需明确显示，不自动清除数据。
- 首个 Beta 的网页、同步和构建结果及其范围保留在 [验证记录](./docs/VERIFICATION.md)。GitHub Release 已撤下，不能从公开发布页下载该包。

新标签页初始化和渲染只读取本地数据与资源，不等待动态媒体开始播放。用户启用 WebDAV 或 S3 同步后，扩展打开、本地变更和手动操作会触发同步。各提供方凭据只保存在当前 Chrome 配置文件的本地扩展存储；远端配置、全部壁纸素材、图标和媒体原件由端到端加密保护。当前格式为 Dexie 13、ZIP `formatVersion: 10`、同步快照 `schemaVersion: 12`，显式接收并升级上一版本的 Dexie 12、ZIP 9 和同步 11，以及当前 Beta 2 的 Dexie 11、ZIP 8 和同步 10（见 [搜索设计](./docs/SEARCH-DESIGN.md)）。旧分组数据库、含 `groups`/`groupId` 的旧 ZIP 和同步快照明确拒绝，不自动转换、重编号或清空本地数据、同步身份及远端库。用户接受旧分组版本通过主动卸载重装重新开始；这不是自动迁移或远端删除授权。Google Drive 按用户决定延后。对象接口与顺序见 [docs/SYNC-COORDINATOR.md](./docs/SYNC-COORDINATOR.md)，R2 边界见 [docs/SYNC-S3.md](./docs/SYNC-S3.md)。

本轮搜索的自动与受控扩展检查见验证记录，尚无用户视觉验收结论；真实 R2、窗口焦点专项和新增媒体在真实 WebDAV 服务的组合仍待验收。公开 GitHub Release、附件和 Chrome Web Store 提交都需用户对具体候选版本另行确认。

## 隐私与权限

Orinui 不要求 Orinui 账号，不投放广告、不植入追踪或统计代码。网站、文件夹、设置及媒体保存在本机浏览器数据库。搜索只在用户提交时发给当前选择的搜索引擎；选择在线图片直链下载时，只为用户确认的来源请求权限。WebDAV/S3 仅在用户主动配置并启用后连接指定存储位置，云端同步对象端到端加密。

在设置的数据管理页选择“导出 ZIP”保存完整备份；恢复时选择“导入 ZIP”，检查预览后再确认替换本机数据。导入 ZIP 前应确保选中了正确文件。接受当前 ZIP v10，并严格验证、显式升级 ZIP v9 和文件夹格式 ZIP v8；旧分组 ZIP、开发期 JSON 与 Beta 1 ZIP v1 明确拒绝，不自动清理已有数据。

ZIP 备份保存在用户选择的位置，默认**不加密**，其中包含网站、设置以及壁纸素材库中的照片、动态媒体原件和被引用图标。请自行妥善保管备份。ZIP 不包含 WebDAV/S3 登录凭据、恢复密钥或同步运行状态；提供方凭据保存在当前 Chrome 配置文件的扩展本地存储。

基础安装权限用于扩展本地存储。网站来源权限为可选项，会在用户发起图片下载或 WebDAV/S3 连接操作时请求；`webRequest` 只用于用户主动发起的图片直链下载。打开新标签页不会为了渲染背景请求网络。实际权限以发布包 manifest 和 Chrome 的授权提示为准。

Orinui 源码依照 [GNU GPL v3](./LICENSE) 发布；生产依赖的许可证和版权声明随扩展文件提供：[THIRD_PARTY_NOTICES.txt](./public/THIRD_PARTY_NOTICES.txt)。

WebDAV 表单默认使用坚果云，提供 Koofr、Nextcloud 与自定义模板；S3 表单支持自定义 HTTPS endpoint，Cloudflare R2 作为首个验证目标。受控测试和模板本身不是实际服务兼容验收。WebDAV 地址见 [docs/SYNC-WEBDAV.md](./docs/SYNC-WEBDAV.md)，S3 条件操作和 CORS 要求见 [docs/SYNC-S3.md](./docs/SYNC-S3.md)。

## 开发环境与命令

采用 WXT、React、TypeScript、Tailwind CSS v4、shadcn/ui 和 Dexie。开发机使用 Node.js v24；依赖要求以 `package.json`、锁文件和所用工具的运行要求为准。

```bash
pnpm install
pnpm dev
```

| 命令 | 说明 |
|---|---|
| `pnpm dev` | 启动开发模式并加载 Chrome 扩展 |
| `pnpm compile` | TypeScript 类型检查 |
| `pnpm test` | Vitest 单元与集成测试，整个进程限时 60 秒 |
| `pnpm build` | 生产构建到 `.output/chrome-mv3` |
| `pnpm test:browser` | 构建后运行 Chrome 普通网页预览测试 |
| `pnpm zip` | 生成发布压缩包；打包成功不等同于已发布 |

真实扩展验收：在 `chrome://extensions` 开启开发者模式，加载 `.output/chrome-mv3`，从 `chrome-extension://` 页面检查权限、吸管和扩展自身信息。普通网页预览不能替代这些检查；测试范围与 Windows 执行环境问题见验证记录。
