# Orinui

设计精致、轻量、本地优先的新标签页扩展。无账号、无广告、无追踪。

产品定位与需求见 [docs/PROJECT.md](./docs/PROJECT.md)，界面设计见 [docs/VISUAL-SPEC.md](./docs/VISUAL-SPEC.md)，数据结构与操作规则见 [docs/DATA-CONTRACT.md](./docs/DATA-CONTRACT.md)。

## 当前进度

已完成工程基础、本地数据层与核心交互：

- WXT + React + TypeScript + Tailwind CSS v4，Manifest V3，仅 Chrome 目标。
- 语义设计令牌、浅色/深色主题与系统偏好跟随；抽屉与弹窗具备过渡动画并尊重减少动态效果。
- 主页三个固定插槽（时钟、搜索、快捷方式），按持久化的顺序与显示状态渲染。
- 时钟跟随系统区域设置；搜索在当前标签页提交到默认引擎 Google。
- 分组标签切换、网站网格（宽屏最多 6 列、窄屏自适应、整行居中）；空分组显示“添加第一个网站”。
- 网站与分组的管理都在主页：右键格子或标签即可打开操作菜单（编辑、排序、跨组移动、删除、改名），不依赖 hover，也不占用设置抽屉。
- 分组标签行末尾的「编辑」按钮切换编辑模式：进入后格子与标签可拖动排序、每项出现可 Tab 聚焦的「⋯」按钮，网格末尾出现「＋ 添加网站」格子；`Shift+F10` 也能打开右键菜单，键盘用户不必拖动。
- 设置抽屉（右侧）分「外观 / 布局 / 关于」，不再包含网站与分组分区。
- 单个网站删除后提供 5 秒撤销提示；删除分组为二次确认并显示组内网站数量；失败信息以提示条呈现，字段错误显示在对应表单字段上。
- 本地数据层（Dexie）：分组与快捷方式的事务化增删改、排序、跨组移动、默认分组不变量、数量上限。
- 领域校验：网址规范化、字素簇长度限制、布局配置校验、搜索模板校验、设置校验。
- 外观设置：主题（跟随系统/浅色/深色）、背景（默认/纯色/渐变）、动态取色（跟随背景或手动选色）、布局显示与排序控件。
- 取色用自建面板：饱和度/明度面板 + 色相条 + 十六进制输入 + 屏幕吸管，键盘可达任意颜色；不使用系统取色弹窗，因为它由浏览器绘制、无法跟随应用样式。
- 动态配色在设备本地由 Material 官方算法从背景生成，只覆盖强调色与壁纸之上的半透明表面；壁纸之上的文字按背景明暗决定，保证可读性。
- 数据表结构升级到版本 2（外观字段 + 图片资源表），首次迁移有测试覆盖。
- 157 个单元与集成测试通过。
- 生产构建产物可直接作为 Chrome 未打包扩展加载，且不产生任何外部网络请求。

尚未实现（随后续阶段推进）：

- 照片背景：本地上传与图片直链下载、照片遮罩强度、从照片提取种子色。
- 图标来源：文字以外的内置图形、本地上传与图片直链下载。
- JSON 导入导出与本地重置。
- 联网搜索建议（服务尚未核验，默认关闭）。
- 随包内置的自然摄影背景：授权素材尚未引入，当前使用中性渐变占位。

## 开发环境

- Node.js 20 及以上（开发机使用 v24）
- pnpm

```bash
pnpm install
```

## 常用命令

| 命令 | 说明 |
|---|---|
| `pnpm dev` | 开发模式，自动打开 Chrome 并加载扩展 |
| `pnpm build` | 构建生产包到 `.output/chrome-mv3` |
| `pnpm zip` | 打包为可上传的压缩包 |
| `pnpm compile` | 类型检查（`tsc --noEmit`） |
| `pnpm test` | 运行单元与集成测试（Vitest） |

本地验证：执行 `pnpm build` 后，在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，指向 `.output/chrome-mv3`。

## 目录结构

```text
public/icon/            扩展图标（随包静态资源）
src/
  entrypoints/newtab/   新标签页入口（HTML 与挂载）
  app/                  页面组合、背景层、主题
  components/ui/        shadcn/ui 组件（Base UI + luma 样式）
  domain/               领域类型与纯规则：插槽、搜索引擎、设置校验、网址与文本校验
  features/             按功能划分的界面：clock、search、shortcuts、groups、appearance、settings
  hooks/                跨功能复用的 React 钩子
  lib/                  通用工具
  platform/             扩展 API、导航与屏幕吸管的薄封装，便于未来适配其他浏览器
  storage/              Dexie 数据库、仓储、排序维护与事务
  styles/               设计令牌与全局样式
tests/
  domain/               领域规则测试
  features/             与界面共用的纯逻辑测试
  platform/             平台封装边界行为测试
  storage/              数据层事务与持久化测试
  setup/                测试环境（内存 IndexedDB）
```

## 技术约束

- 仅使用语义颜色令牌，不硬编码颜色；颜色与暗色模式由 `src/styles/globals.css` 统一管理。
- 不在首页发起网络请求；联网能力必须由用户明确启用。
- `src/platform` 是唯一调用扩展 API 的位置，浏览器差异集中在此。
- `src/components/ui` 由 shadcn CLI 生成，保留上游代码风格；其余源码使用单引号与分号。
- 使用 shadcn CLI 添加组件时，若生成的导入被写成 `cn` 包，需改回 `@/lib/utils` 并移除误装的依赖。
