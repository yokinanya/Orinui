## 已实现功能

- **主页与管理**：时钟、搜索、分组和网站网格；宽屏最多 6 列、窄屏自适应。右键菜单、编辑模式、拖动及键盘排序、跨组移动、分组改名与删除。网站删除可在当前会话内撤销。
- **外观**：系统/浅色/深色主题，中性渐变、纯色、渐变、照片背景，照片遮罩，本机动态配色，自建取色面板与屏幕吸管入口。
- **图片**：本地照片和图标上传、安全静态 SVG 栅格化、尺寸/体积校验；图片链接回填后可手动更新，同来源重定向继续、跨来源再次确认；内置图标使用图形选择器，编辑时实时预览。页面仍只读本地图片，不自动抓取 favicon。
- **搜索、时钟与布局**：内置和自定义搜索引擎、12/24 小时制、三个主页区域的显示与排序，以及全部隐藏后的恢复入口。
- **本地数据**：Dexie 数据库版本 3、跨表事务、资源引用清理、自包含图片的 JSON 备份版本 1、导入预览与覆盖确认、本地重置。

新标签页初始化和渲染只读取本地数据与资源。当前联网由用户提交搜索、打开网站或主动下载图片触发。应用尚未连接同步提供方；已实现的手动协调接口需调用方显式注入对象存储，见 [docs/SYNC-COORDINATOR.md](./docs/SYNC-COORDINATOR.md)。

## 尚未完成

Dashboard Icons 参考外链、仅清除图片来源信息、主页进入与分组内容切换动效已实现。[UI 检查与复验](./docs/UI-REVIEW.md)中的背景对比、320px 抽屉与取色布局、关闭文案和过渡问题已修复；完整视觉验收和首屏性能仍未完成。

同步将包含分组、网站、设置、照片和图标，提供 Google Drive `appDataFolder`（推荐）和 HTTPS WebDAV 两种选择，并强制端到端加密。当前基础层与手动协调器已完成，包含运行状态、一次性合并基线、串行及失败恢复检查；尚无提供方适配器、连接授权或恢复密钥界面。基础协议见 [docs/SYNC-PROTOCOL.md](./docs/SYNC-PROTOCOL.md)，其余待实施项见任务清单。

## 开发环境与命令

采用 WXT、React、TypeScript、Tailwind CSS v4、shadcn/ui 和 Dexie。开发机使用 Node.js v24；依赖要求以 `package.json`、锁文件和所用工具的运行要求为准。

```bash
pnpm install
pnpm dev
```

| 命令 | 说明 |
|---|---|
| `pnpm dev` | 启动开发模式并加载 Chrome 扩展 |
| `pnpm compile` | TypeScript 类型检查 |
| `pnpm test` | Vitest 单元与集成测试，整个进程限时 60 秒 |
| `pnpm build` | 生产构建到 `.output/chrome-mv3` |
| `pnpm test:browser` | 构建后运行 Chrome 普通网页预览测试 |
| `pnpm zip` | 生成发布压缩包；打包成功不等同于已发布 |

真实扩展验收：在 `chrome://extensions` 开启开发者模式，加载 `.output/chrome-mv3`，从 `chrome-extension://` 页面检查权限、吸管和扩展自身信息。普通网页预览不能替代这些检查；测试范围与 Windows 执行环境问题见验证记录。
